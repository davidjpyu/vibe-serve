The forward path MUST be your own code — `transformers` is allowed only for `AutoConfig`, `AutoTokenizer`, and reading the safetensors shards on disk. Do NOT call `AutoModelForCausalLM` or any modeling_qwen3_5* class in the forward path.

Architecture (read `reference/config.json` and `serving-systems/references/models/ssm-hybrid.md`):
  - 32 decoder layers following `text_config.layer_types`: pattern is 3×linear_attention + 1×full_attention, repeated 8×.
  - Embedding: hidden=4096, vocab=248320, `tie_word_embeddings=false` (LM head has its own weights).
  - Pre-norm transformer: RMSNorm(eps=1e-6) before attention, before MLP, plus final norm.
  - MLP: SwiGLU, intermediate_size=12288 (gate_proj, up_proj, down_proj; `act = silu(gate) * up`).
  - Full-attention layer: GQA with num_heads=16, num_kv_heads=4, head_dim=256. `attention_bias=false`. `attn_output_gate=true` — there is an output gate (sigmoid) applied to the attention output before o_proj; mirror exactly what HF does (read the HF source in your venv's `transformers/models/qwen3_5/modeling_qwen3_5.py`). RoPE is partial (`partial_rotary_factor=0.25`) and uses `mrope_interleaved=true` with `mrope_section=[11,11,10]` and `rope_theta=1e7`; only the first `int(head_dim * 0.25) = 64` dims rotate, the remaining 192 dims pass through. KV cache stored per-layer per-request.
  - Linear-attention layer (Gated DeltaNet / GDN): `linear_num_key_heads=16`, `linear_num_value_heads=32`, `linear_key_head_dim=128`, `linear_value_head_dim=128`, `linear_conv_kernel_dim=4`. There is a causal conv-1d cache of width 3 (kernel_dim-1) per layer per request. State per request per layer is `(num_value_heads, key_head_dim, value_head_dim)` GDN recurrence state, and a `(conv_kernel-1, hidden)` conv state. Use `fla` (flash-linear-attention) for the actual recurrence — install with `pip install flash-linear-attention causal-conv1d` into the active venv if not present, then call `fla.ops.gated_delta_rule.chunk_gated_delta_rule` for prefill and `fla.ops.gated_delta_rule.fused_recurrent_gated_delta_rule` for single-token decode. If `fla` cannot be installed in this environment, implement a Python chunked-recurrence reference (correctness over speed for R1).
  - LM head: linear over hidden -> vocab. Skip the MTP head entirely (it's optional; main LM head only).
  - Vision tower: skip loading those weights entirely. Read only `text_config` and `tie_word_embeddings`.

Weight loading: discover safetensors shards in `model_dir`, walk the HF `model.safetensors.index.json`, map HF parameter names to your modules; skip every parameter prefixed `vision_` / `visual.` / `mtp.`. Cast to the dtype passed to `from_pretrained` (the accuracy checker uses fp16). Loading must work on a single H200.

Decode loop: implement a simple per-request KV-cache + GDN-state holder; prefill processes the prompt in one shot (or in chunks for very long prompts), then decode loop generates one token per step greedily. EOS handling: stop at `eos_token_id=248044` if hit before `max_new_tokens`.
