### Summary
Baseline FastAPI server for Llama-3.1-8B-Instruct on H200 (`main.py`, ~700 LOC, single file). Built every layer by hand: RMSNorm (variance in fp32), Llama-3-scaled RoPE (factor=8, low/high freq factors 1/4, original_max_pos=8192, with the piecewise-linear smoothing), GQA attention (32 Q / 8 KV heads, head_dim=128, scaling=1/sqrt(head_dim)), SwiGLU MLP, and a 32-deep `LlamaDecoderLayer` stack. KV cache is preallocated per layer to `max_cache_len=4096` and written in-place via slice-assignment — no `torch.cat` against the cache anywhere in the decode path. `VibeServeModel.from_pretrained` loads safetensors shards directly into the hand-written modules via state_dict mapping (no `LlamaModel`/`LlamaForCausalLM`/`LlamaDecoderLayer` from transformers is instantiated; tokenizer + AutoConfig + safetensors are the only HF touchpoints). `generate` runs greedy on the static cache: prefill at cache_start=0 (causal SDPA, kv_len==q_len), then single-token decode steps at incrementing `cache_start` with `is_causal=False`. GPU access serialized through `asyncio.Lock`; decode loop runs inside `@torch.inference_mode()` via a producer thread + asyncio queue so streaming chunks flush as tokens land.
